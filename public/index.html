User Guide

🚀 Getting Started

Welcome to NoteBook! Here's how to make the most of your private space:

  • Create: Tap the + button or press N in the Command Palette.
  • Organize: Use Folders for projects and Categories for quick filtering.
  • Search: Press Ctrl + K to open the Command Palette and find anything instantly.

✍️ Markdown Cheatsheet

NoteBook supports lightweight Markdown for rich formatting:

**Bold** ➔ Bold
*Italic* ➔ Italic
# Header ➔ Large Title
[ ] Task ➔ Interactive Checklist
`Code` ➔ Inline code

🎙️ Voice & Tools

  • Voice-to-Text: Tap the mic icon in the editor to dictate your thoughts.
  • Reminders: Set a date/time to receive browser notifications.
  • PDF Export: Download your notes as clean PDFs for sharing.
